# GLS Companion

**GLS Companion** is a Windows companion application developed for the Great Lakes Syndicate Star Citizen community.

It provides quick access to GLS community tools while playing Star Citizen, including:

- GLS Cargo Hauling Optimizer
- GLS Salvage Optimizer
- Full, Compact, Run View, and Park modes
- Always-on-top companion window
- Cargo and Salvage sessions maintained independently while the application is running
- F9 show/hide hotkey when Windows has access to the keyboard input
- Live GLS web tools, allowing tool improvements to appear without requiring a new Companion release

## Current Release

**v0.1 Beta**

This is an initial public beta. Bugs and unexpected behavior may occur.

If you encounter a problem, please report it through the GitHub Issues section.

## Star Citizen Compatibility

GLS Companion is a standard Windows desktop companion application.

It does not inject into Star Citizen, modify the game client, read game memory, or interact directly with the Star Citizen process.

Depending on your Star Citizen display/input configuration, the game may capture keyboard and mouse input while it has focus. In that situation, Alt+Tab may be required before interacting with GLS Companion.
